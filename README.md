# Nginx Load Balancer Project

## Project Overview
This project demonstrates how Nginx can be used as a load balancer to distribute incoming requests across multiple backend servers.

## Key Requirements
- Install and configure Nginx as a load balancer.
- Set up multiple backend server instances.
- Configure Nginx to distribute traffic across the backend servers.
- Demonstrate that requests are shared between the backend servers.

## Technologies Used
- Nginx
- Linux
- Web Server
- Load Balancing
